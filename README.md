# AgentSpace Development Dashboard

Public static dashboard for tracking development of the private AgentSpace
platform.

## How it works

- `data/status.json` contains the complete allowlisted public projection:
  product roadmap, master execution checklist, current operational gate,
  verified evidence, and live Safe Parallel lifecycle.
- Verified-main GitHub Actions and the local runtime observer are separate
  publication paths for the same validated schema.
- `data/status.json` is generated by private AgentSpace tooling and must not be
  edited manually.
- `app.js` renders the single validated status contract with safe DOM APIs.
- `index.html` provides the page structure.
- `styles.css` controls presentation and responsive behavior.

This public repository has no private-repository credentials or access. It is
never authoritative for planning or runtime state. If publication fails, the
last projection remains available and becomes stale after seven days.
